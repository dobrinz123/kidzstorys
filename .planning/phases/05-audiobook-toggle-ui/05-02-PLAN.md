**Addition 3 — bookHasAudio memo (immediately after the store selector line, before existing useEffect blocks):**
```typescript
// Compute once when book or language changes. Checks if ANY page has completed audio
// for the current language. Per ANTI-PATTERN note in research: do NOT check per-page
// to prevent toggle flickering during page turns.
const bookHasAudio = useMemo(() => {
    if (!convexBook) return false;
    const statusKey = `audioStatus_${currentLang}` as `audioStatus_en` | `audioStatus_ro`;
    return convexBook.pages.some((page) => page[statusKey] === "done");
}, [convexBook, currentLang]);
```
Note: TypeScript may not accept the template literal key directly. If so, cast to `keyof typeof page` or use `(page as any)[statusKey]` — prefer avoiding `any` but this is acceptable here since the field type is well-defined in ConvexBook.

**Addition 4 — resetAudiobook on unmount (add a new useEffect, placed with the other cleanup useEffects around lines 134-152):**
```typescript
// Reset audiobook toggle when leaving reader — ensures next book opens with toggle OFF.
// Per AUDIO-04: state persists within a session; reset only on unmount (exit).
useEffect(() => {
    return () => {
        resetAudiobook();
    };
}, [resetAudiobook]);
```

```tsx
<View style={styles.header}>
    <TouchableOpacity style={styles.backButton} onPress={goBack}>
        <Text style={styles.backText}>{"\u2190"} {ui.back}</Text>
    </TouchableOpacity>
    <Text style={styles.title} numberOfLines={1}>
        {title}
    </Text>

    {/* Audiobook toggle — only for Convex books that have audio for current language */}
    {convexBook && bookHasAudio && hasAccess && (
        <TouchableOpacity
            style={styles.audiobookToggle}
            onPress={toggleAudiobook}
            accessibilityLabel={isAudiobookEnabled ? "Turn off audiobook" : "Turn on audiobook"}
            accessibilityRole="button"
        >
            <Ionicons
                name={isAudiobookEnabled ? "headset" : "headset-outline"}
                size={24}
                color={isAudiobookEnabled ? BOOK_COLORS.buttonBg : BOOK_COLORS.textSecondary}
            />
        </TouchableOpacity>
    )}

    {/* Lock icon for non-PREMIUM users when book has audio — taps to paywall */}
    {convexBook && bookHasAudio && !hasAccess && (
        <TouchableOpacity
            style={styles.audiobookToggle}
            onPress={() => router.push("/(paywall)")}
            accessibilityLabel="Unlock audiobook"
            accessibilityRole="button"
        >
            <Ionicons
                name="lock-closed-outline"
                size={20}
                color={BOOK_COLORS.textSecondary}
            />
        </TouchableOpacity>
    )}

    <Text style={styles.pageNumber}>
        {currentPage + 1} / {totalPages}
    </Text>
</View>
```

- Both branches are mutually exclusive — no double render possible
- Per AUDIO-05: when `isAudiobookEnabled` is false, zero audio logic executes anywhere; reader behaves identically to before
