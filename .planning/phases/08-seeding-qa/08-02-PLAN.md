  <name>Task 1: End-to-end playback test — 10 books, both languages</name>
  <what-built>All published books have EN and RO audio (confirmed in 08-01). The mobile reader has an audiobook toggle, a playback engine (useAudiobook hook), and auto page-turn wired to didJustFinish.</what-built>
  <how-to-verify>
    Pick 10 books at random from different categories and age ranges. For each book, run the following checklist:

    ENGLISH pass:
    1. Open the book. Set app language to English.
    2. Tap the headphone icon to enable audiobook mode.
    3. Confirm audio starts playing on the first page (AUDIO-02).
    4. Listen until the page finishes. Confirm the page auto-turns with the existing flip animation (AUDIO-03).
    5. Continue for 3-4 pages. Confirm each page plays and auto-turns without manual interaction.
    6. Tap the headphone icon again to turn audiobook OFF. Confirm audio stops (AUDIO-01, AUDIO-04).
    7. Close and reopen the book. Confirm audiobook is OFF by default (AUDIO-04 — persists within session only, resets on new session).

    ROMANIAN pass (same book, repeat with different book):
    1. Switch app language to Romanian.
    2. Reopen a book (or use the same one — language switch should reload audio, LANG-01, LANG-02).
    3. Enable audiobook mode.
    4. Confirm Romanian audio plays on each page and auto-turns correctly.

    For each of the 10 books record: book title, EN result (pass/fail), RO result (pass/fail), any issues.
  </how-to-verify>
  <resume-signal>Type "playback QA done" and paste your 10-book results table (book name, EN pass/fail, RO pass/fail).</resume-signal>

<task type="checkpoint:human-verify">
  <name>Task 2: Voice quality spot-check (VOICE-01, VOICE-02, VOICE-03)</name>
  <what-built>ElevenLabs eleven_multilingual_v2 model was used with the configured EN and RO voice IDs. Voice settings: stability 0.5, similarity_boost 0.75.</what-built>
  <how-to-verify>
    Select 2 books with varied sentence structure (one simple, one with longer descriptive text).

    For each book listen to the first 3 pages in each language and evaluate:

    English voice checklist:
    - Voice sounds warm and natural (not robotic) (VOICE-03)
    - Prosody is appropriate for children's stories (soft, engaging) (VOICE-01)
    - No clipping, distortion, or audio artifacts
    - Sentence endings sound natural (not cut off)

    Romanian voice checklist:
    - Voice sounds natural with correct Romanian pronunciation (VOICE-02)
    - Appropriate children's story tone (VOICE-03)
    - No clipping, distortion, or audio artifacts
    - Diacritics (ă, â, î, ș, ț) pronounced correctly

    If voice quality is unacceptable: note which voice ID is problematic and what the issue is. The fix is to update the ELEVENLABS_EN_VOICE_ID or ELEVENLABS_RO_VOICE_ID env var to a different voice, then retrigger generation for affected books.
  </how-to-verify>
  <resume-signal>Type "voice quality approved" (or "voice quality issue: [description]" if a voice needs to be changed).</resume-signal>
</task>

<task type="checkpoint:human-verify">
  <name>Task 3: Memory leak test — 20+ pages with audiobook ON (AUDIO-06, AUDIO-08)</name>
  <what-built>The useAudiobook hook unloads the Sound object on every page change via a cleanup effect. Preloading fetches the next page's audio URL while the current page plays.</what-built>
  <how-to-verify>
    Choose a long book (10+ pages) or chain two books together to reach 20+ pages.

    1. Enable audiobook mode.
    2. Let the book auto-turn through all 20+ pages without manual interaction.
    3. After the final page, observe:
       - App is still responsive (no sluggish taps, no delayed renders)
       - No error toasts or crash dialogs appeared during playback
       - Memory usage has not grown unboundedly (iOS: check Xcode Instruments -> Memory if available; otherwise observe subjectively)
    4. Navigate back to the home screen. Confirm the app is fully responsive.
    5. Open a different book and confirm normal (non-audiobook) reading still works.

    Pass criteria: No crash, no visible freeze, no audio overlap from a previously unloaded Sound object, app fully usable after the session.
  </how-to-verify>
  <resume-signal>Type "memory test passed" or describe any degradation observed.</resume-signal>
</task>

<task type="checkpoint:human-verify">
  <name>Task 4: Regression test — reading without audiobook ON (AUDIO-05)</name>

    If you have a non-PREMIUM test account:
    6. Log in as non-PREMIUM. Open a book. Confirm the headphone icon is either hidden or shows a lock icon (not an active toggle). Confirm tapping the lock navigates to the paywall (ACCESS-02).

    Pass criteria: Non-audiobook reading is indistinguishable from pre-feature behavior.
  </how-to-verify>
  <resume-signal>Type "regression passed" or describe any behavioral change from the pre-feature baseline.</resume-signal>
