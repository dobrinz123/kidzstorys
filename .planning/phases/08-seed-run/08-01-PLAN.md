<task type="checkpoint:human-verify">
  <name>Task 4: Monitor generation progress until complete</name>
  <what-built>The processAudioQueue cron runs automatically every 30 seconds, picking up to 5 pending jobs per tick and calling generatePageAudio for each. The admin dashboard /dashboard/audio shows live progress.</what-built>
  <how-to-verify>
    Monitor the admin dashboard at /dashboard/audio. Refresh periodically (or watch live if using Convex reactive queries).

    Check getAudioOverview values:
    - totalPages: total page count across all published books
    - doneEn: should climb toward totalPages
    - doneRo: should climb toward totalPages
    - failedCount: watch for failures; use "Retry All Failed" button if > 0

    You can also query directly:
      npx convex run audio:getAudioOverview '{}'

    Generation is complete when:
      doneEn === totalPages AND doneRo === totalPages
      (or failedCount is acceptable and all retries are exhausted)

    If jobs stall (no progress for 5+ minutes):
    1. Check Convex Dashboard -> Functions -> Logs for errors in processAudioQueue or generatePageAudio.
    2. Common causes: ElevenLabs API key invalid, voice ID wrong, rate limit hit.
    3. Fix the root cause, use "Retry All Failed" on the dashboard, and continue monitoring.

    This may take 30 minutes to several hours depending on the number of books and ElevenLabs rate limits (max 100 req/min, 5 jobs/30s = ~10 req/min — well within limits).
  </how-to-verify>
  <resume-signal>Type "generation complete" and include the final getAudioOverview counts: totalPages, doneEn, doneRo, failedCount.</resume-signal>
</task>
