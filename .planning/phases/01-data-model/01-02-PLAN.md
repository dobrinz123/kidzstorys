# Plan 01-02: Create audioJobs Table With Indexes

## Objective
Add the `audioJobs` table to `convex/schema.ts`. This table tracks one generation job per page per locale (EN or RO), carrying status, retry count, error messages, and a reference back to the batch that spawned it. This is the core data structure that drives the generation pipeline in Phase 3, and satisfies GEN-02 (per-page generation status tracking).

> **Pages are embedded in `books`**: Because `pages` is not a standalone table, `audioJobs` references a page by `bookId: v.id("books")` + `pageIndex: v.number()` (zero-based index into `books.pages`), not by a page document ID.

## must_haves
- `convex/schema.ts` contains an `audioJobs` table definition
- `audioJobs` has required fields: `bookId`, `pageIndex`, `locale`, `status`, `retryCount`, `createdAt`
- `audioJobs` has optional fields: `audioStorageId`, `audioUrl`, `textHash`, `errorMessage`, `batchId`, `completedAt`
- `audioJobs` has indexes: `by_status`, `by_book_locale`, `by_batch`
- `status` field is a union of exactly four literals: `"pending"`, `"generating"`, `"done"`, `"failed"`
- `locale` field is a union of exactly two literals: `"en"`, `"ro"`
- `npx convex dev --once` exits 0

<read_first>

<action>
Open `convex/schema.ts`. After the closing `,` of the last table in the CONTENT section and before the `// ============ LEGACY STORIES` comment, insert the following block exactly:

```typescript
  // ============ AUDIO GENERATION ============
  // Per-page audio generation job tracking
  audioJobs: defineTable({
    bookId: v.id("books"),
    pageIndex: v.number(),           // zero-based index into books.pages array
    locale: v.union(v.literal("en"), v.literal("ro")),
    status: v.union(
      v.literal("pending"),
      v.literal("generating"),
      v.literal("done"),
      v.literal("failed")
    ),
    audioStorageId: v.optional(v.id("_storage")),
    audioUrl: v.optional(v.string()),
    textHash: v.optional(v.string()), // SHA-256 of page text at generation time
    errorMessage: v.optional(v.string()),
    retryCount: v.number(),
    batchId: v.optional(v.string()),
    createdAt: v.number(),
    completedAt: v.optional(v.number()),
  })
    .index("by_status", ["status"])
    .index("by_book_locale", ["bookId", "locale"])
    .index("by_batch", ["batchId", "status"]),

```

The trailing comma after `.index("by_batch", ...)` is required because more tables follow.
</action>
