# Plan 01-01: Extend Embedded Page Objects With Audio URL and Storage ID Fields

## Objective
Add eight optional audio fields to every page object inside `books.pages` (the embedded array in `convex/schema.ts`). These fields store the Convex File Storage IDs, the derived public URLs, per-locale generation status, and generation timestamps for EN and RO audio. Satisfies GEN-01 at the page-data level.

> **Critical context**: `pages` is NOT a separate Convex table. It is a `v.array(v.object({...}))` embedded inside the `books` table. All audio fields must be added inside that `v.object({...})`, not as a new table.

## must_haves
- `convex/schema.ts` `books.pages` array item object contains `audioUrl_en: v.optional(v.string())`
- `convex/schema.ts` `books.pages` array item object contains `audioUrl_ro: v.optional(v.string())`
- `convex/schema.ts` `books.pages` array item object contains `audioStorageId_en: v.optional(v.id("_storage"))`
- `convex/schema.ts` `books.pages` array item object contains `audioStorageId_ro: v.optional(v.id("_storage"))`
- `convex/schema.ts` `books.pages` array item object contains `audioStatus_en: v.optional(v.union(...))` — optional; `undefined` means "no audio generated yet" (intentional design: status only set when a job exists)
- `convex/schema.ts` `books.pages` array item object contains `audioStatus_ro: v.optional(v.union(...))` — same semantics
- `convex/schema.ts` `books.pages` array item object contains `audioGeneratedAt_en: v.optional(v.number())`
- `convex/schema.ts` `books.pages` array item object contains `audioGeneratedAt_ro: v.optional(v.number())`
- `bookVersions.snapshot` pages object also contains the eight audio fields (mirrored to keep snapshot shape in sync)
- `npx convex dev --once` exits 0 (TypeScript types regenerated, no schema errors)
