### Subscription Flow (CRITICAL - COMPLET)
```
User Signs Up (entitlementActive: false)
    ↓
Browse Stories (locked overlays)
    ↓
Tap Story → Redirected to Paywall
    ↓
View Packages → Purchase
    ↓
RevenueCat Processes Payment
    ↓
Webhook Fires → Convex Updates Entitlement
    ↓
Live Query Refreshes → Content Unlocked
    ↓
Full Story Access + Parent Questions
```

### Recommendation Algorithm (IMPLEMENTED)
```typescript
Score =
  + 50 (category match)
  + 40 (age bracket perfect match)
  + 20 (duration proximity)
  + 30 (child state boost for calming tags)
  - penalty for recently read
  + popularity bonus (capped)

Tie-breaker: publishedAt desc
```

## 🚀 NEXT STEPS - DEPLOYMENT

### 1. Install Dependencies
```bash
pnpm install
```

### 2. Setup Convex
```bash
cd convex
npx convex login
npx convex dev
# Copiază CONVEX_URL din output
```

### 3. Configure Environment Variables

**convex/.env:**
```bash
REVENUECAT_WEBHOOK_SECRET=your_secret_from_revenuecat
ADMIN_ALLOWLIST_SEED_EMAILS=admin@example.com
```

**apps/mobile/.env:**
```bash
EXPO_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
EXPO_PUBLIC_REVENUECAT_IOS_KEY=appl_xxxxx
EXPO_PUBLIC_REVENUECAT_ANDROID_KEY=goog_xxxxx
EXPO_PUBLIC_REVENUECAT_ENTITLEMENT_ID=premium
```

**apps/admin/.env.local:**
```bash
NEXT_PUBLIC_CONVEX_URL=https://your-deployment.convex.cloud
REVENUECAT_WEBHOOK_SECRET=your_secret_from_revenuecat
```

### 4. Validate & Seed
```bash
# Validate stories
pnpm validate-stories

# Should output: ✅ All validations passed! 100 stories ready

# Seed database
CONVEX_URL=https://your-url.convex.cloud pnpm seed
```

### 5. Run Applications
```bash
# Terminal 1: Convex dev
cd convex
npx convex dev

# Terminal 2: Mobile app
pnpm mobile

# Terminal 3: Admin panel
pnpm admin
```

### 6. Setup RevenueCat
1. Create project at revenuecat.com
2. Add iOS + Android apps
3. Create entitlement: `premium`
4. Add products (monthly/yearly)
5. Setup webhook:
   - URL: `https://your-admin.com/api/revenuecat-webhook`
   - Events: INITIAL_PURCHASE, RENEWAL, CANCELLATION, EXPIRATION
6. Copy webhook secret to .env files

### 7. Deploy to Production

**Convex:**
```bash
cd convex
npx convex deploy
# Set env vars in Convex dashboard
```

**Mobile (EAS):**
```bash
npm install -g eas-cli
eas build --platform ios --profile production
eas build --platform android --profile production
eas submit --platform ios
eas submit --platform android
```

**Admin Panel (Vercel):**
```bash
cd apps/admin
vercel --prod
# Set env vars in Vercel dashboard
```
